## Task 1: Use Big O Notation to describe the time complexity of an algorithm that takes 4N+16steps.
**Response**: The time complexity of this algorithm is O(N)
## Task 2: Use Big O Notation to describe the time complexity of an algorithm that takes 2N^2 steps
**Response**: The time complexity of this algorithm is O(N^2)
## Task 3: Use Big O Notation to describe the time complexity of the following function, which returns the sum of all numbers of an array after the numbers have been doubled
**Response**: N steps are needed each for doubling and adding them, respectively. making the total steps 2N, but the time complexity is O(N)
## Task 4: Use Big O Notation to describe the time complexity of the following function, which accepts an array of strings and prints each string in multiple cases
**Response**: There is 3 operations for each element in the array, which makes the total steps 3N, but the time complexity is O(N)
## Task 5: The next function iterates over an array of numbers, and for each number whose index is even, it prints the sum of that number plus every number in the array. What is this function’s efficiency in terms of Big O Notation?
**Response**: The inner loop performs n operations, but it only runs n/2 of the time, meaning the total number of steps is (N^2)/2 making the time complexity O(N^2)
